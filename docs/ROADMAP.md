# Roadmap

## Current checkpoint — public playable demo

- Four-step mobile experience
- Manual spin entry through an interactive European betting cloth
- Physical European-wheel sector analysis
- 12-, 14-, or 16-pocket sector selection
- Three progressive inside-bet style combinations
- Automatic full-sector coverage
- Calculated chip requirement
- €5 or €10 chip values
- Live visual chip placement during ticket configuration
- Exact pleno, caballo, tercio, and cuarta table positions
- Final ticket with the same visual placement map and numbered bet list
- Per-result ticket economics
- Public ChatGPT Sites deployment

## Next — engineering release

- Mirror the portable application source
- Extract deterministic TypeScript domain modules
- Add unit tests for wheel order, legal bet shapes, cloth coordinates, optimiser, and payouts
- Add mobile interaction tests
- Add automated lint, type-check, and test workflow
- Add PWA manifest and offline verification

## Visual polish

- Refine wheel heatmap and sector animation
- Improve chip overlap handling on especially dense tickets
- Improve outside-coverage and overlap explanations
- Add reduced-motion and accessibility modes
- Add repository screenshots and a short demo video
- Add a portfolio case-study page

## Post-MVP research

- Screenshot/OCR input with mandatory manual verification
- Casino-specific zero-split configuration
- Non-financial session analytics
- American roulette support
- Dealer/wheel-bias research mode using substantially larger datasets and explicit statistical thresholds

## Deliberately out of scope

- Real-money account integration
- Automated casino interaction
- Bet placement automation
- Martingale or loss-chasing systems
- Claims that recent spins predict the next result
